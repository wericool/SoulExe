## Этап 2. Единая модель разговоров

- [x] Ввести сохранённую сущность `ConversationSnapshot` с произвольным набором участников, сообщениями, контекстом и состоянием хода. Schema v10 хранит её напрямую в `Conversations`.
- [x] Заменить противопоставление «чат / сцена» на режимы одного разговора: один AI-персонаж или несколько AI-персонажей. Desktop UI, runtime-сервисы, стартовые данные, импорты и проверки работают через `ConversationSnapshot`. `ConversationRuntimeProjection`, старые типы `SoulChat`/`SoulScene`, converter/preflight schema v8/v9 и API fallback физически удалены. Файлы schema ниже v10 теперь явно отклоняются как неподдерживаемые.
- [x] Хранить автора каждой пользовательской реплики как участника разговора: выбранная персона пользователя либо специальная роль «Режиссёр».
- [x] Разрешить менять активную персону пользователя прямо в композиторе; смена действует только на следующие сообщения и не меняет историю.
- [x] Разрешить в групповом чате переключать композер между выбранной персоной и «Режиссёром». Режиссёрское сообщение — системное событие, а не ответ одного из персонажей.
- [x] Подключить выбор автора в desktop-композере к каноническому сохранению: в личном и групповом разговоре доступны «Вы», сохранённые персоны и «Режиссёр». Имя, avatar snapshot, persona id и тип автора сохраняются на каждой новой реплике.
- [x] Сохранить для каждой реплики отображаемые имя, аватар и тип автора, чтобы старая история не менялась после редактирования персоны.
- [x] Убрать скрытое превращение фрагментов `*…*` в установленные факты; действия режиссёра будут только явным типом сообщения.
- [x] Удалить автоматические приветствия: новые, сгенерированные и импортированные карточки персонажей не создают `Greetings` и не добавляют приветственную реплику в историю. Импорт истории Soul of Waifu сохраняет только реальные сообщения исходного разговора.
- [x] Удалить миграционный compatibility-слой schema v8/v9, поскольку старые пользовательские данные отсутствуют и поддерживать их не требуется.
- [x] Удалить двойное хранение `Characters[].Chats` / `Scenes`: schema v10 сериализует только канонические `Conversations`; старых runtime-проекций и классов больше нет.
