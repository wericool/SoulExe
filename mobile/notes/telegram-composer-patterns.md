# Паттерны композера для SoulExe Mobile

Источник для анализа: предоставленный пользователем `ChatActivityEnterView.java` из Telegram Android, GNU GPL v2 or later, строки 2605–2660, 2713–2750 и 5634–5763.

Для SoulExe применяется самостоятельная реализация на React Native без переноса Java-кода. Полезные паттерны: отдельный контейнер ввода с минимальной высотой, внутренняя область текста без собственной декоративной рамки, независимые круглые зоны действий слева и справа, ограниченный рост многострочного ввода и смена правого действия по состоянию текста.

В SoulExe левая кнопка используется для ролевого действия, правое действие — для отправки. Для сцены справа размещаются пауза/запуск и следующая реплика. Поле растёт до ограниченной высоты, а прокрутка текста появляется только после достижения лимита.
