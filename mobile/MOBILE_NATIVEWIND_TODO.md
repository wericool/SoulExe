# SoulExe Mobile — NativeWind / новый интерфейс

## Граница переноса

Новый UI берётся только из `E:\Games\Soulexe_backup\NewStyleMobile\soulexe-mobile-handoff`.

Из старого мобильного приложения разрешено переносить только функциональный код: API локального сервера SoulExe, поиск сервера в Wi-Fi, сессию, синхронизацию данных и загрузку файлов. Старые экраны, компоненты, стили, темы, глобальные патчи `Pressable` и разметка не используются.
