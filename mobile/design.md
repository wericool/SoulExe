# SoulExe Mobile — мессенджерный интерфейс

## Назначение

SoulExe Mobile — нативный Android-клиент локального SoulExe на ПК. Он не содержит Telegram-код, брендинг, протокол или сетевую инфраструктуру: загруженные исходники используются только как референс проверенных мессенджерных паттернов — плотной ленты диалогов, явной верхней навигации, компактных строк, устойчивой ленты сообщений и удобного поля ввода.

Интерфейс рассчитан на **портретный экран 9:16** и управление одной рукой. Основная точка входа — список разговоров, а не набор крупных карточек. Все списки строятся на `FlatList`; одинаковая высота строк, предсказуемые размеры аватаров и стабильное закреплённое поле ввода предотвращают визуальные скачки.

## Экраны

| Экран | Основной контент и функциональность |
|---|---|
| Подключение | Автопоиск SoulExe в LAN, ручной адрес, вход по учётным данным, сохранённая защищённая сессия. |
| Входящие чаты | Плотный список диалогов с аватаром, именем, одной строкой предпросмотра, временем и индикатором генерации; поиск и кнопка нового диалога. |
| Диалог | Верхняя панель с персонажем, лента сообщений с разделителями дат, «печатает…», кнопка перехода к последнему сообщению и закреплённое поле отправки. |
| Сцены | Такой же список строк сцен и отдельная лента реплик; статус работы, старт/пауза, следующая реплика и режиссёрское событие. |
| Персонажи | Компактный список карточек, создание и редактирование персонажей в существующем API SoulExe. |
| Настройки | Подключение к ПК, состояние сервера, выход и повторный поиск. |

## Основные пользовательские потоки

| Сценарий | Путь |
|---|---|
| Первое подключение | Открыть приложение → найти ПК в Wi‑Fi/LAN или ввести адрес → войти → увидеть список диалогов. |
| Обычный чат | Список диалогов → открыть строку → прочитать последние реплики → написать сообщение → увидеть локальное подтверждение, индикатор генерации и ответ. |
| Сцена | Список сцен → открыть строку → увидеть свежие реплики → запустить/поставить на паузу, запросить ход или отправить режиссёрское событие. |
| Новый разговор | Нажать кнопку создания → выбрать персонажа и название → открыть созданный диалог. |
| Смена ПК | Настройки → изменить подключение → новый поиск или ручной URL → войти заново. |

## Компоновка и взаимодействие

| Элемент | Правило |
|---|---|
| Строка списка | Высота 68–72 px, аватар 44 px, имя и предпросмотр слева, время справа; один размер у всех строк. |
| Верхняя панель | Высота 56 px, кнопка назад, название и статус, контекстное действие справа. |
| Лента | Растягивается на всю свободную высоту и автоматически открывается на последней реплике. |
| Поле ввода | Закреплено внизу, поднимается над клавиатурой, растёт максимум до четырёх строк. |
| Обратная связь | Отправленная реплика видна сразу; состояние «формирует ответ» показывается до появления ответа; мелкие действия имеют заметное нажатие. |

## Ограничения реализации

SoulExe Mobile остаётся отдельным продуктом со своей иконкой, названием, локальным API и фиолетово-синим стилем. Он не использует название, логотипы, исходный код или серверные компоненты Telegram. История чатов и сцен читается только из уже работающего локального SoulExe; внешняя синхронизация и облачное хранение не добавляются.
