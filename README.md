# SoulExe

SoulExe — локальная система для ролевых ИИ-чатов с персонажами и сценами. Данные, локальная LLM и сетевой мобильный доступ работают на компьютере пользователя; облачное хранение переписок не требуется.

## Структура

| Каталог | Содержимое |
|---|---|
| `desktop/` | Windows WPF-клиент на .NET 8, локальный HTTP API и встроенный LAN-веб-клиент. |
| `mobile/` | Native Expo/React Native-клиент для Android/iOS, подключающийся к запущенному SoulExe в Wi-Fi/LAN. |

## Запуск Windows-клиента

Откройте `desktop/SoulTextWpf.csproj` в Visual Studio с поддержкой .NET 8 и Windows SDK либо выполните:

```powershell
dotnet build desktop/SoulTextWpf.csproj -c Release
```

Для работы с локальной моделью укажите путь к `llama-server.exe` и GGUF-модели в параметрах SoulExe. Данные приложения сохраняются рядом с запускаемым EXE в `SoulExeData/`; эта папка намеренно исключена из Git.

## Запуск Mobile-клиента

```bash
cd mobile
pnpm install
pnpm check
pnpm test
pnpm android
```

На компьютере запустите SoulExe, в разделе **Параметры → Мобильный** включите локальный сервер либо его автозапуск, после чего подключите телефон к тому же Wi-Fi/LAN.

## Что не публикуется

Репозиторий не содержит скомпилированные EXE/APK, `bin/`, `obj/`, `node_modules/`, кэши Expo, ZIP-архивы, логи, токены, `.env`-файлы, данные `SoulExeData/` и реальные переписки.

## Происхождение

SoulExe является отдельной развиваемой версией. Оригинальные исходники Soul of Waifu не включены в этот репозиторий; сведения об оригинальном проекте и его лицензии приведены в [UPSTREAM.md](UPSTREAM.md).
