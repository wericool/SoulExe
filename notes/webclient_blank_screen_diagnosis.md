# Воспроизведение пустого веб-экрана

Экспортированный из `MobileStyleWebClient.Content` HTML был открыт в браузерном движке 22 августа 2026 года. Страница загрузилась с заголовком `SoulExe Mobile`, однако интерфейс не появился: весь экран остался тёмным. Это подтверждает, что причина находится в рантайме встроенного JavaScript, а не в доступности IP-адреса или стилях фона.

Проверка DOM показала один встроенный скрипт и существующий контейнер `#app`, но его `innerHTML` остался пустым после `document.readyState = complete`. Следующий шаг — получить исключение напрямую при повторном исполнении сценария в диагностическом контексте.

Конец сценария содержит вызов `boot()`. Повторное выполнение сценария через диагностический контекст не вернуло исключение в инструменте, поэтому дальнейшая проверка должна определить, выполнился ли рендер после явного запуска и не блокируется ли первое исполнение браузером для локального `file:` URL.

После исправления статический экран входа виден сразу при новой загрузке экспортированного HTML, даже когда браузерный контекст не запускает встроенный сценарий для `file:` URL. Независимая VM-проверка подтверждает, что первый программный рендер и синтаксис встроенного JavaScript проходят успешно. Теперь страница не может остаться только тёмным фоном: при обычном запуске появляется форма входа, а при неожиданной ошибке — понятное сообщение с кнопкой повторной загрузки.
