# Защита данных при объединении разговоров

Этот список применяется к каждому этапу рефакторинга в ветке `testing`.

| Инвариант | Обычный чат | Сцена |
|---|---|---|
| Идентификатор | `SoulChat.Id` сохраняется как идентификатор нового разговора. | `SoulScene.Id` сохраняется как идентификатор нового разговора. |
| Участники | Пользователь и владелец-персонаж. | Оба персонажа; режиссёр — отдельный тип события, а не потерянный текст. |
| История | Последовательность, время, варианты и вложения не теряются. | Последовательность, время, автор и режиссёрские события не теряются. |
| Контекст | Стартовые факты, Summary, Soul Memory и state variables остаются доступными. | Сценарий, место, цель, отношения, Summary и состояние следующего хода остаются доступными. |
| Откат | Старый JSON резервируется до миграции. | При нарушении инварианта новая схема не становится активной. |

Автономный проект `desktop/SoulExe.ConversationChecks` содержит синтетические фикстуры обычного чата и сцены. В следующих этапах к нему добавляются проверки адаптеров, миграции и общего API.
